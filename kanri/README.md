# 写真の入れ替え画面

サイトの写真を、ブラウザから差し替えるための画面です。
HTMLを触らずに、写真だけを入れ替えられます。

## 何ができるか

- サイト内の写真枠を自動で一覧表示（HTMLを読んで探すので、ページが増えても勝手に増えます）
- 「仮画像」「差し替え済み」がひと目で分かる
- 写真を選んでボタンを押すだけで差し替え
- iPhone の写真の回転を自動で直す
- 幅 1600px まで自動で縮小・圧縮
- 差し替える前の写真は `_backup/` に日時つきで残る

線画のアイコン（`images/icons/`）は編集対象に含みません。

## 設置（さくら・初回のみ）

1. `kanri/` フォルダーごと `www/` の直下にアップロードする
   （`index.php` / `save.php` / `lib.php` / `.htaccess`）

2. **パスワードをかける**
   さくらのコントロールパネル →「アクセス制限」で `kanri` フォルダーに
   ユーザー名とパスワードを設定します。
   ※ 設定していないと画面上部に赤い警告が出ます。必ず設定してください。

3. `images/` フォルダーに書き込み権限を与える（755 または 775）

4. `https://（ドメイン）/kanri/` を開く

## 大きな写真が弾かれるとき

さくらの初期設定では、アップロードできる大きさに上限があります。
`kanri/` に `.user.ini` を作ると上げられます。

```
upload_max_filesize = 20M
post_max_size = 21M
memory_limit = 256M
```

反映まで数分かかることがあります。

## 大切なこと — 転送で消えないように

写真は**さくら側が正**です。`deploy.sh` は `images/` と `kanri/` を
転送対象から外してあるので、サイトを更新しても差し替えた写真は消えません。

逆に言うと、**git 側の `images/` は古いまま**になります。
差し替えた写真を git にも残したい場合は、FTPで落として commit してください。

## 戻したいとき

`kanri/_backup/` に `images_service-new.jpg.20260728-141530.bak` の形で
残っています。FTPで拡張子を `.jpg` に戻し、元の場所へ上書きしてください。
